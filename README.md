# 视觉素材图鉴 · 海大叔版

一个纯静态的中文视觉素材检索站：**3925 条素材**，配效果图，搜到就能抄。

- **239 条** 动效 / 运镜 / 画风 / 光线 / 图表术语，含 Canvas 实时预览与 1318 个中文口语别名（「推近」「甩镜」「逆光」都能搜）
- **3686 条** 中文绘画提示词，覆盖海报 / 建筑 / 美食 / 产品 / 人像 / 直播画面
- **24 条** 口播实战配方：直接把术语翻译成能对剪辑师说的镜头语言

无后端、无登录、无追踪，打开即用。

## 目录结构

```
index.html      单页应用（内含动效数据 DATA）
prompts.js      绘画提示词数据 window.PROMPTS
demo.js         动效渲染代码（Canvas 2D）
styles.json     动效数据源文件（与 index.html 内嵌 DATA 同步）
packs/          画风预览所需图像资源
```

## 数据来源

| 数据 | 来源 | 协议 |
|---|---|---|
| 动效 / 运镜 / 画风术语 | [showheyohtaki/motion-prompt](https://github.com/showheyohtaki/motion-prompt) | MIT |
| 中文绘画提示词 | [BaYue-SYJ/shuixian-prompts](https://github.com/BaYue-SYJ/shuixian-prompts) | 以原库声明为准 |

原库共 6601 条提示词，本站只保留可复用的通用视觉题材。

## 内容清洗说明

为保证站点面向中文口播 / 新媒体场景的可用性，生成阶段做了以下剔除：

- 日文原文条目 **428** 条（正文含日文假名）
- 日本角色向题材 **1767** 条（动漫、二次元、和风、和服、神社、日本 IP 等）
- 擦边低俗 **720** 条
- 另有 **143** 条国风、建筑、人像等通用题材因原分类名误挂日本题材分类，已改归中性分类后保留
- 动效源同步剔除日本传统题材 1 条；上游英文说明中的日文界面示例文案已全部汉化为中文

**当前站点与数据中不含任何日文字符与日本题材内容。**

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也可运行（file:// 协议下图片可正常加载）。

## 增强

- 动效术语补 1318 个中文别名，支持口语化检索（渐隐、甩镜、饼图、逆光、闪烁等）
- 卡片视图分页渲染（每页 48 条），缩略图进入视口才绘制、离屏即释放，8GB 内存机器无压力
- 提示词图片懒加载，抽屉内展示大图与完整提示词，支持一键复制
